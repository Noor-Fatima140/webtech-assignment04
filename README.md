# Markdown Slide Presentation Web Application

This project is built using HTML, CSS (Tailwind CSS), JavaScript, and Marked.js.

## Key Features
1. **Markdown Editor & Realtime Preview**: 2-section split screen layout for live editing and previewing.
2. **Slide Delimiter**: Slides are created by separating markdown content using `---` line breaks.
3. **Internal Storage Save**: Saves presentations automatically/manually in browser `localStorage`.
4. **Navigation Controls**:
   - Disabled **Left** button on slide 1.
   - Disabled **Right** button on final slide.
   - Dynamic **Full Screen** / **Exit Full Screen** toggle button.
5. **Slide Counter**: Formatted exact format `{current slide number} / {total number of slides}`.
6. **Keyboard Shortcuts**:
   - `Left Arrow`: Previous slide
   - `Right Arrow`: Next slide
   - `F11`: Toggle Presentation Mode
   - `Ctrl + S`: Save to Browser Internal Memory

## How to Run
1. Unzip `Markdown_Presentation_App.zip`.
2. Double click `index.html` to open in any browser (Chrome, Edge, Firefox, Safari).
